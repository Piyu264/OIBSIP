# Stopwatch Application

## OASIS INFOBYTE – Android App Development

### Project Description

A functional Android stopwatch application developed using Android Studio, Java, and XML.

The application accurately tracks elapsed time and provides Start, Pause, Reset, and Lap functionality.

## Features

- Start stopwatch
- Pause/Stop stopwatch
- Resume from paused time
- Reset stopwatch
- Millisecond precision
- Lap time recording
- Scrollable lap list
- Dynamic button states
- Android lifecycle handling

## Technology Stack

- Android Studio
- Java
- XML
- Android SDK
- Handler
- Runnable

## Task

**Track:** Android App Development

## How to Run

1. Open the project in Android Studio.
2. Allow Gradle to sync.
3. Connect an Android device or start an Android Emulator.
4. Click the Run button.
5. Use Start, Pause, Reset, and Lap controls.
