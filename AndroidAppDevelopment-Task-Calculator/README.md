## Project Description

A clean and fully functional Android calculator application developed using Android Studio, Java, and XML.

The application performs basic arithmetic operations through a responsive button-grid interface.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Clear button
- Backspace button
- Equals button
- Division-by-zero error handling
- Mathematical operator precedence
- Decimal input validation
- Responsive button grid
- Safe handling of repeated button taps

## Technologies Used

- Android Studio
- Java
- XML
- Android SDK
- GridLayout
- TextView
- Button
- OnClickListener
- StringBuilder
